# Fandango Rating Bias Analysis (2015 vs 2016)

An investigation into whether Fandango adjusted its inflated movie rating system after the bias was publicly exposed in 2015.

---

## Overview

In 2015, Fandango's ratings were found to be systematically inflated. This project compares rating distributions from 2015 and 2016 to determine whether the platform made meaningful corrections.

---

## Objectives

- Compare Fandango rating distributions across 2015 and 2016
- Compute summary statistics (mean, median, mode)
- Analyze frequency of high ratings (4.5–5 stars)
- Draw data-driven conclusions on rating inflation

---

## Tools

Python · pandas · matplotlib · Google Colab

## Key Findings

Rating distributions shifted noticeably between 2015 and 2016, with a reduction in the concentration of inflated high ratings — suggesting Fandango did adjust its system following public scrutiny.
